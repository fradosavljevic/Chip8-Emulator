# Chip8-Emulator

A low-level implementation of the CHIP-8 architecture, written in C. This project was developed to explore the challenges behind architectural emulation — specifically, how to structure a program that replicates the behavior and state management of physical hardware.

# Usage

```bash
.\chip8.exe roms/Chip8Picture.ch8
```
